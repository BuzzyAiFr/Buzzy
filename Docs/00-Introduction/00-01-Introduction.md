# Bienvenue dans la Documentation de Buzzy

## Qu'est-ce que Buzzy ?

Buzzy est un **framework d'outillage pour agents IA**, conçu pour décupler leurs capacités et leur permettre de réaliser n'importe quelle tâche de manière autonome ou en assistance d'un utilisateur. Il agit comme une "boîte à outils universelle" qui transforme les Grands Modèles de Langage (LLM), même les plus modestes, en acteurs surpuissants capables d'interagir avec un environnement de développement, d'analyser du code, de se refactoriser et d'exécuter des plans complexes.

La mission de Buzzy est double :
1.  **Pour l'humain :** Fournir un outil et un framework pour automatiser les tâches de développement.
2.  **Pour l'IA :** Servir de base de connaissances et d'ensemble d'outils que les agents peuvent utiliser pour leur propre développement et auto-amélioration.

## À qui s'adresse cette documentation ?

Cette documentation est destinée à trois publics :

1.  **Les Agents IA :** Elle est structurée pour être lisible par une machine, afin que Buzzy puisse apprendre de sa propre documentation pour s'améliorer.
2.  **Les Développeurs :** Ceux qui veulent comprendre l'architecture pour créer de nouveaux **nœuds** (capacités), écrire des **workflows** (processus) ou intégrer de nouveaux **agents**.
3.  **Les Utilisateurs :** Ceux qui veulent utiliser Buzzy via son interface en ligne de commande (CLI) pour automatiser des tâches sur leurs propres projets.

## Vision du projet

L'objectif à long terme de Buzzy est de devenir un standard pour l'automatisation intelligente dans le cycle de vie du développement logiciel. Il vise à fournir un cadre robuste où des agents IA peuvent collaborer, apprendre et évoluer pour assister les développeurs humains de manière proactive et pertinente.
